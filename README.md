![Status](https://img.shields.io/badge/Status-Demo-orange) ![License](https://img.shields.io/badge/License-MIT-blue) ![Contributions](https://img.shields.io/badge/Contributions-Welcome-brightgreen)

## 📌 Project Overview
This project is a **EUR/USD Price Predictor** that utilizes machine learning techniques to forecast currency prices. The UI is built with **Bootstrap** and integrates with a backend to process predictions.

> ⚠ **Important Tip:** This program is for **educational purposes only**. **Do not** use it for real trading decisions. The predictions are part of a demo for larger projects.

---

## 🎨 Features
✅ Beautiful UI with **Bootstrap & Flatpickr**  
✅ Interactive charts for price visualization 📈  
✅ Fast predictions with an optimized backend ⚡  
✅ Multiple model selection options 🤖  
✅ Real-time currency input & analysis 💰

## 🛠 Tech Stack
- **Frontend:** HTML, CSS, Bootstrap, Flatpickr
- **Backend:** Flask / FastAPI
- **Machine Learning:** Scikit-learn, DecisionTreeRegressor, LGBMRegressor
- **Data Visualization:** Matplotlib, Plotly
